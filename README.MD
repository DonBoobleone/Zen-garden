# Zen Garden - A Mod for Factorio Space Age

## Recipes
- Compost from wood or spoilage -> spoils into Artificial-grass
- Zen-wood: 100 wood for 2000 water-  made in Zen-garden
- Soil mixing: Mix landfill and artificial grass with nutrients to get more artificial grass.
- Charcoal burning: Smelt Wooden chests into coal - (optional)

## Artificial Grass
- Natural grass tile
- Spoils from compost
- Consumes pollution
- Viable instead of landfill (Option: Invasive Forestry - Allows usage on Gleba as well)
- 2 more decorative versions - (optional)
![Cosmetic variations](https://raw.githubusercontent.com/DonBoobleone/Zen-garden/refs/heads/main/readme_images/artificial-grass-variations.png) 

## Wood production 
- Zen Tower: A small early agricultural tower for Nauvis, plants on a 2x2 compact grid - (optional)
- Zen Tower MK2: A large agricultural tower for both Gleba and Nauvis, plants on a 2x2 compact grid - (optional)
- Zen Garden: A standalone high tier building with a pressure dome, can be placed on any surface. Has 4 module slots - (optional)

## Seeds
- Bonsai Seed - (optional)
- Extended seed selection - (optional)

## Cosmetics with pollution filtering capabilities 
- Zen-tree in a portable planting box, for each tree type (alien-biomes-compatible) - (optional)
- Zen-Bonsai / Cherry-Bonsai, decorative that needs water, has a special underground only connection built in. - (optional)
![Bonsai](https://raw.githubusercontent.com/DonBoobleone/Zen-garden/refs/heads/main/readme_images/bonsai-underground-connection.png) 
- Gear-garden: Consumes pollution and water - (optional)

## Cosmetics
- Zen Grenade - Clears craters/sand-dunes/nest-remains while keeping vegetation intact. (Known issue - Game will only update visuals upon placing artificial tiles in the area or saving and loading the game.Will be fixed in base>=2.1)
